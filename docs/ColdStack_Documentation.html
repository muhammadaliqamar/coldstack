1. System Overview

ColdStack is a self-hostable, open-source alternative to SaaS platforms like Instantly, Lemlist, and Smartlead. It provides everything modern sales teams need to run high-volume cold email campaigns while protecting domain reputation through an intelligent, AI-powered warmup engine.

Core Capabilities

  • AI-Powered Warmup: Google Gemini generates realistic conversational emails that bypass spam filters.
  • Deliverability Monitoring: Real-time tracking of bounce rates, reply rates, and inbox health scores.
  • Smart IMAP Engagement: Automated reading, threading, and delayed replying to simulate genuine human interaction.
  • Multi-Domain Management: Manage multiple domains, up to 3 inboxes per domain, and external seed accounts.
  • Campaign Management: Multi-step sequences with conditional logic, open/click tracking, and lead pipeline.
  • Crash-Safe Job Processing: BullMQ + Redis ensures no tasks are lost during server restarts.

3. Installation & Setup

Prerequisites

  • Node.js v18+ • PostgreSQL • Redis

Steps

# 1. Clone
git clone https://github.com/muhammadaliqamar/coldstack.git
cd coldstack

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env
# Edit .env with your DB, Redis, and Gemini API credentials

# 4. Initialize database
npm run db:push
npm run db:seed

# 5. Start everything (API + Web + Workers)
npm run dev

The dashboard is available at http://localhost:3000 and the API at http://localhost:4000.

5. Warmup Engine (Core Feature)

The warmup engine is ColdStack's most critical subsystem. It gradually builds domain reputation over 6 weeks using AI-generated emails and simulated human engagement.

Engagement Simulation Flow

  1. Send: AI-generated email sent via SMTP.
  2. Wait 30 min – 1.5 hrs: Simulates delivery time.
  3. Auto-Read (IMAP): Connects to recipient's inbox, finds the email, marks as \Seen.
  4. Wait 30 min – 3 hrs: Simulates human reading time.
  5. Auto-Reply (SMTP): Gemini generates a contextual reply and sends it back.
Crash Safety: Each email is enqueued as an individual persistent BullMQ job in Redis. If the server shuts down, remaining jobs resume automatically on restart.

Safety Mechanisms

  • Bounce Rate Auto-Pause: If bounce rate exceeds 5%, the inbox is automatically paused.
  • Week Gating: Users must manually approve progression to each new week.
  • Volume Jump Cap: Daily limit cannot increase by more than +5 per day to avoid sudden spikes.
  • Weekend Throttling: Weekends are capped at 2 emails/day maximum.
  • Friday Prayer Block: Emails are paused during GST Friday prayer hours (12–2 PM).

8. AI Integration (Google Gemini)

ColdStack uses Google Gemini to generate two types of content:

Warmup Email Generation

Gemini generates batches of 30 realistic B2B emails (subject + body) that are cached in Redis. These emails look like normal office communications — meeting follow-ups, quick questions, scheduling calls — not marketing templates.

Reply Generation

When the auto-reply worker fires, Gemini generates a short, contextual reply (1–3 sentences) based on the original email's subject line, mimicking a fast, casual business response.

Model Configuration: Set GEMINI_MODEL in your .env file to use any Gemini model (default: gemini-2.5-flash).

9. Security

  • Credential Encryption: All SMTP/IMAP passwords are encrypted at rest using AES-256.
  • JWT Authentication: All API endpoints are protected with short-lived JWT tokens.
  • Rate Limiting: 100 requests/minute per user via express-rate-limit.
  • Helmet: HTTP security headers applied via helmet.
  • Environment Isolation: .env is gitignored; only .env.example is committed.
